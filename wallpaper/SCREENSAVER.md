> 材料は**マイ壁紙で焼いたスプライトをそのまま使う**（`wallpaper/dist/`）＝この機能のためのビルドは無い。
> **現在地：3方式＋収録（15秒動画）＋「自分の1台を主役にする」まで実装し、2026-09-05 に実機（iPhone Safari）で通った。同日、正式版化（`noindex` 解除・`canonical`・`og:image`・`sitemap` 登録）まで済んでいる。**

> ⛔ **導線はまだ付けない**（CLAUDE.md の掟）。**メニュー・トップ本文・他ページからのリンクはどれも無い**＝検索からは入れるが、サイト内に入口はまだ無い状態。
> ⭕ **【2026-09-05 ユーザー確定】3方式とも残す。⛔削らない。方式1（タイル＆ピックアップ）を「顔」として扱う。**
> 削る実益が無い（分岐は1ファイルの中の数十行で維持の負担がほぼゼロ）のに対し、

## §2 収録モード（15秒の動画）

**ねらい＝Instagram リール / TikTok にそのまま上げられる15秒。** ヒントの「🎬 15秒の動画を撮る」から入る。
3つ数える → 15秒録画 → 「保存・共有」（Web Share）／「ハッシュタグをコピー」／「もどる」。

- ⚠️⚠️ **`captureStream` は canvas の中身しか拾わない**＝DOM で重ねた文字は録画に写らない。
  だから収録中は **UI を全部隠し（`body.rec .layer{display:none}`）、クレジットと車両情報を canvas に焼き込む**。
- ⚠️ **SNS は 9:16、iPhone の画面は 9:19.5 前後＝画面収録した動画は上下が切られる。**
  大事な文字は**中央 9:16 の内側**（`safeBox()`）に置く。TikTok は右にボタン列・下にキャプションが重なるので下端ぎりぎりも避ける。
- クレジット＝**`Registro500/126 Giappone` / `registro500.com`**（2026-09-05 ユーザー確定。⭐壁紙は500・126共通の1枚なので併記する）。
  ⚠️ 白い車のタイルの上だと白文字が沈むので、下端に控えめなグラデーションを敷いてある（⛔板は置かない）。
- **収録中だけ方式1の間合いを詰める**＝1.5秒 壁が流れる → 1台目 → 2台目 → 最後は壁で締まる（周期 0.8+3.6+0.7+1.6＝6.7秒）。
- ⚠️ **`canvas.width/height` は2の倍数へ丸める**＝H.264 は幅・高さが奇数だと録れないことがある。
- ⚠️ **`navigator.share` はユーザー操作から直に呼ばないと拒まれる**（iOS）。だから15秒後に自動で共有シートを出さず、**録り終えてから押してもらう**。
- **MP4 か WebM かは端末次第**＝Safari は MP4／Chrome は WebM。⚠️**Instagram・TikTok は WebM を受け付けない**ので、WebM のときは画面にその旨を出す。
- **MediaRecorder が無い端末でも収録モードは意味がある**＝UI を消した画面をそのまま**端末の画面収録**で撮れる（フォールバックとして案内する）。

## §3 「自分の1台を主役にする」（2026-09-05 実装・実機で通った）

**ログインすると、ピックアップの1台目が必ず自分の車になる。** メールOTP＝マイ壁紙と同型。

- ⛔ **見た目に飾りを足さない**（囲み線もオーバーレイも置かない＝マイ壁紙と同じ思想）。
  **大きく出ること自体が主役**で、差は**1秒長く留まること**だけ。
- **収録に入ったときも1台目が自分**＝3つ数えている間に連れてくる。
- ⚠️ **判定がつかないときは主役を立てない**（マイ壁紙 §4-2 と同じ）＝取り違えると他人の車を「あなたの1台」として出すことになる。
- ⭐ **ログインしなくても絵は全部見られる**＝入口は控えめに、断っても何も失われないようにする。
- 見つからない理由は4つに出し分ける：**お車が見あたらない／SNS掲載オフ／メイン写真なし／焼き直し待ち**。
- ⚠️ **supabase-js はログインが要るときだけ読む。** `localStorage` のセッション鍵（`sb-…-auth-token`）を見て、
  **ログイン済みの人だけ静かに読みに行く**＝この画面は「開いて放置」が本分なので起動を重くしない。
- 確認用の逃げ道＝**`?mine=<番号>`**（マイ壁紙の `?hi=` と同型）。ログインせずに動きを見られる。

### 3-1 `seekMine`＝自分の車を画面へ連れてくる（⛔ここを単純化しない）

流れてくるのを待つと**最悪2分かかる**（171台÷列数×7秒）ので、**格子の行だけ飛ばす**。位相（`frac`）は保つので流れは途切れず、「別の場所が流れてきた」ようにしか見えない。

⚠️⚠️ **自分が出る列は固定される。** 格子は `絶対行×列数 + 列 ≡ 位置 (mod 171)` なので、解は `gcd(列数, 171)` の周期になり、**列は `mod(位置, gcd)` に貼り付く**。
⛔ **その列がたまたま左右の端だと、ピックアップの候補から必ず落ちる**（`startFocus` は端で切れたタイルを選ばない＝`xpad < 0` なので両端は常に切れている）＝**永久に主役になれない**。
だから**端でない列に出る行を優先**して探し、**3回試して見つからなければ主役を諦める**（`g.seekTry`）＝無限に待たせない。

## §4 不変条件・踏んだ罠（⛔同じ轍を踏まない）

### 4-1 ⚠️⚠️ canvas の汚染は「書き出さない」だけでは免れない

当初は「ここでは canvas から書き出さないので汚染されても構わない」と考えて Firebase Storage の写真を直接描いていた。
**動画の保存を足した時点でこれは崩れた**＝汚染された canvas は `captureStream` も拒む（`SecurityError: Canvas is not origin-clean`／`toBlob`・`getImageData` と同じ扱い）。
⚠️ **Firebase Storage は CORS ヘッダを返さない**ので、`crossOrigin="anonymous"` でも読めない（実測で確認）。

⭐ **対処は2つ**：
1. **汚れは canvas【要素】の一生に紐づく**ので、収録に入るとき**要素ごと作り直してリセットする**（`freshCanvas`）。
2. **収録中はスプライト（同一オリジン）だけで描く**＝写真は通常再生でのみ使う。

⛔ **方式2（スライドショー）はアプリ内録画に対応しない。** 写真そのものが主役でタイルでは代わりにならず、しかも写真を描いた時点で録画できなくなる。
**出せないボタンを出さず、「動画にするには端末の画面収録を使ってください」と理由を1行で言う。**

### 4-2 実機で気づいた3つ（どれも PC で作っていて見落とした）

- ⚠️⚠️ **キーボードのある PC で作ってそのまま出さない。** ヒントに `1 2 3` `←→` とキーの絵を並べたが、iPhone では**方式を切り替える手立てが皆無**だった（ユーザー指摘）。**押せるボタンを必ず置く**＋ヒントの表示は9秒（短いとボタンを探しているうちに消える）。
- ⚠️ **メイン写真は 1000×1000 の正方形**（`edit.html` の cropper）。cover で画面いっぱいにすると iPhone 縦で約1.7倍＋Ken Burns で約1.9倍に伸び、**ギザギザが出て左右も切れる**。⭐だから **contain（全体を収める）＋同じ写真のぼかしで余白を埋める**（フォトフレームの作法）＋動きは「近づく」側だけ（0.97→1.00）。
- ⚠️⚠️ **`Math.round` で位置を丸めるとカクつく。** 方式3のレーン境目の隙間を埋めるつもりで丸めたが、縦は毎秒5px程度しか進まないため**1pxずつ飛んだ**。⛔丸めない＝**`T+1` で1px重ねて隙間を防ぐ**。💡方式1が滑らかで方式3だけカクついていたのは、方式1では丸めていなかったから。

### 4-3 その他

- ⚠️ **iOS Safari は `<a download>` が効かない**＝保存の道は Web Share だけ（マイ壁紙 §6 と同じ）。
- ⚠️ **Fullscreen API は iPhone Safari が非対応。** ホーム画面に追加して開けば `manifest.json`（`display:standalone`）で全画面になる＝**PWA を新たに触る必要はない**。
- ⚠️ **Wake Lock はユーザーが1回触ってからでないと許可されない。低電力モード中は効かない。**
- ⭐ **車両情報は素の REST で読む**（`supabase-js` を読まない）＝認証が要らないので起動が軽い。
- ⚠️ `lastTs` は**秒**。`lastTs / 1000` と書いた箇所があり、モード切替のたびに即ピックアップが走っていた（修正済）。

### 6-1 `og:image` の作り方（⭐描き起こさない・実物を撮る）

**別に版下を描くと、画面を直したときに絵だけ古くなる。**だから**動いている画面をそのまま撮る**：

```bash
python -m http.server 8899          # repo ルートで
# Playwright を 1200×630 にして http://localhost:8899/screensaver.html を開く
#   → 「はじめる」を押す
#   → #clock,#badge,#hint,#info を display:none にする（時計が焼き込まれると古びる）
#   → 9秒ほど待って、ピックアップが開いている瞬間を撮る
# 撮った PNG の下辺にクレジットを焼く（文言と配置は drawCredit() に合わせる）
#   Registro500/126 Giappone ／ registro500.com ＋ 下から立ち上がる黒のグラデ
# 最後に JPEG（quality 86・progressive）で保存 → og/screensaver-ja.jpg
```

- ⚠️ **実写のグリッドは PNG だと 1.2MB になる**＝ここだけ JPEG（213KB）。`og/` の他のファイルが PNG なのは版下（べた塗り＋文字）だから。
- ⚠️ **時計を映さない。**撮った日の時刻がカードに焼き付いて、半年後に嘘になる。
- ⭐ **ナンバーの写り込みは可**（成長方針で確定済み）。ただし `sns_share_optout` の車はそもそもデータに入っていない。
