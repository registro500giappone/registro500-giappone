# クラシックFIAT 500 日本国内台数の調査結果

> 依頼: 「日本で何台くらい走っているか」を根拠をもって調べる。
> **2代目（Nuova 500 / 1957〜1975）限定。3代目（2007〜）が混じらないこと。**
> 調査日: 2026-08-03

---

## 結論

**無料で公開されている統計に、この数字は存在しません。**
ただし **6,050円で正確に取得できる公式統計書があります。**

---

## 推奨：『輸入車 自動車保有車両数』（自動車検査登録情報協会）

| 項目 | 内容 |
|---|---|
| 発行 | 一般財団法人 自動車検査登録情報協会（自検協・AIRIA） |
| 掲載軸 | **輸入自動車の車名・ブランド別 × 初度登録年別 × 排気量別 × 車種別** |
| 仕様 | A4判 394頁 |
| 価格 | **印刷版 6,050円** ／ 電子データ版 36,630円 |
| 購入 | Web注文・FAX注文（バックナンバーはFAX） |
| URL | https://www.airia.or.jp/publish/book/car.html |

### 🎯 なぜこれが決定打か ―「排気量別」があるから

ご懸念の「3代目が混じらないように」は、**排気量で完全に分離できます。**

| 車両 | 排気量 |
|---|---|
| **2代目 FIAT 500（1957-1975）** | **479cc / 499cc / 594cc** |
| 3代目 FIAT 500（2007-） | 1,240cc / 1,368cc など |

桁が違うので、混入の余地がありません。車名「500」で絞ったうえで
**排気量 479〜594cc の行だけを読めば、それが2代目の現存台数**です。

### ⚠️ 重要な注意：初度登録年で絞ってはいけません

直感的には「初度登録年1975年以前」で絞りたくなりますが、**これをやると大幅な過少カウントになります。**

車検証の「初度登録年月」は、**日本で最初に登録された年月**です。
つまり1967年製の個体でも、2015年に並行輸入されたなら初度登録年は2015年になります。
クラシック500の多くは近年の輸入なので、初度登録年で切ると大半が漏れます。

**必ず排気量で切ってください。** これが唯一確実な方法です。

## より精密にやる場合：『個別統計データ』（特注抽出）

| 項目 | 内容 |
|---|---|
| 抽出条件 | **車種別・車名別・型式別**を組み合わせて指定可能。車検証記載事項（個人情報除く）も抽出可 |
| 料金 | **定価なし**。条件と項目数・データ量に応じて見積り |
| 手順 | 見積書取得 → 所定の申込書を提出 |
| 納期 | 原則3営業日以内に発送 |
| URL | https://www.airia.or.jp/publish/book/individual.html |

**型式別**が指定できるのが強みです。2代目500の型式（110F、110F.1、110D など）で
直接抽出できれば最も正確ですが、クラシックの並行輸入車は車検証の型式が
「不明」となっている個体も多く、**型式だけで拾うと逆に漏れる可能性**があります。

→ **まず6,050円の『輸入車』統計書で排気量ベースの数字を押さえ、
　　物足りなければ個別抽出を検討する**、という順序を推奨します。

## 参考：もう一つの統計書（今回は不向き）

『**初度登録年別 自動車保有車両数**』A4判703頁・6,930円
- 初度登録年ごとの メーカー別・車名別・車種別・都道府県別
- ⚠️ **注記に「通称名は普通・小型乗用車および小型四輪貨物車のみ対象」**とあり、
  かつ上記の初度登録年問題があるため、クラシック500の把握には不向き

## 調べたが数字がなかった経路

| 経路 | 結果 |
|---|---|
| 国土交通省 自動車保有車両数統計 | 用途別・車種別のみ。車名/排気量の粒度なし |
| e-Stat（政府統計の総合窓口） | 同上 |
| 自検協 Web公開の統計ページ | 総保有台数の推移のみ |
| 中古車サイト（カーセンサー等） | 販売中の在庫数であって現存台数ではない |
| 日本自動車工業会 | 新車販売・生産統計が中心 |

## 記事での使い方の提案

冒頭の問いかけ「日本で何台くらい走っているかご存知ですか？」に対して、
**出典を明記した数字**を置ければ、記事全体の信頼度が一段上がります。

書き方の案：
> 「一般財団法人 自動車検査登録情報協会の統計によると、○○○台です」

さらに、その数字と **registro500 の登録台数150台超** を並べると、
サイトが日本のクラシック500の何割を捕捉しているかが示せます。
これは自慢ではなく、**サイトの意義を示す事実**として機能します。
