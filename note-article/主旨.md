## ✅ 書きたいこと

### 1. 動機（本人原稿にあり）
- 5年前、衝動買いのような形でチンクに出会った。旧車とは全く縁のない生活だった
- 先輩オーナーに助けられて楽しくやってこられた。SNSで知り合った20年30年選手たちが、
  ノウハウを惜しげもなく教えてくれる
- 旧車ライフは、クルマ自体の楽しさだけでなく**それを取り巻く人々との関わりが醍醐味**
- もらうばかりだった自分も恩返しがしたい、と思ったのが**ちょうど昨年の今頃**（2025年8月頃）

### 2. 素人でも形にできた、という事実
- ノーコードのCMを見て「これを使えば何かできるかも?」
- **プログラムの知識はゼロのまま**、最終的にここまで来た
- 腕が上がったのではない。**道具が変わった**

### 3. 作り方の視点（← ここが主旨の実践部分）
- 各メニューは **「こんなものがあったらいいな」「これがあればチンクオーナーが
  喜んでくれるかな」** という視点で作った
- **自分よがりなので、作ったはいいが使われないメニューも多数ある**
  ← この正直さは記事の説得力になる。隠さない
- **それでも、まだまだメニュー追加意欲は湧いている**

### 4. 読者への呼びかけ
- あなたも、自分の推しのファンサイトを作ってみてはどうですか

## 文体（本人原稿から抽出・厳守）

本人が書いた原稿こそが記事の声。**Claudeが書き手を演じない。続きを書く。**

| 特徴 | 例 |
|---|---|
| 読者に語りかける | 「ご存知ですか？」「醍醐味ですよね♪」「そこがまた面白いところですよね！」 |
| 力が抜けている | 「ぼーっと考えていた」「遅々として進みません」「なんてことを漠然と思い」 |
| 自嘲・率直 | 「私の落ち度でしかないのですが」「お詫びをして一旦撤収」 |
| 具体的な情景 | 「路上にうつ伏せになって車体の下を覗き込むオーナーも」 |
| 感嘆 | 「何度助けられたことか！」 |
| **太字強調をほぼ使わない** | ← Claudeの癖と正反対。持ち込まない |
| 改行が多く、一文が短い | |
| 絵文字を軽く使う | 「醍醐味ですよね♪」「投稿が伸びなかった💦」 |
