【プロジェクト概要】

・プロジェクト名：Registro500 Giappone
・目的：
　- クラシックFiat500（110D/110F/126系）のオーナー情報を登録・公開するプラットフォームを、
　　Firebase＋Google Sheets＋Google Sites＋Google Apps Script（GAS）で「完全無料」で構築する。
　- 一般閲覧者は一覧／詳細を閲覧可、登録・編集はログインユーザーのみ。

・現在の技術構成（ざっくり）：
　- Firestore / Storage：写真とメタデータ
　- Google Sheets：cars シートがマスター
　- GAS：
　　- main.gs（一覧・詳細・Model_Display系ロジック 等）
　　- index.html / detail.html / edit.html
　　- sync_firestore.gs（Firestore⇄Sheets 同期）
　- GitHub：上記ファイルの最新版を保管（実行環境ではなくコード倉庫）

・このチャットで主に扱いたいファイル：
　- レポジトリ：registro500-giappone
　- パス：gas/sites/XXXX（例：main.gs）
　- このあと、GitHub最新版またはコード全文を貼ります。
　- 貼ったコードを「このチャットでの唯一の正」として扱ってください。


【このチャットでの進め方のルール】

1. 作業は一歩一歩、質疑応答を重ねながら進めてください。  
   - いきなりゴールまで飛ばさず、「次の1ステップ」単位で提案してください。

2. 勝手にコードを書いて先に進めないでください。  
   - 私が「ここまでOK」「次に進んで」と言うまでは、大きなコード変更案は出さないでください。
   - 途中で確認したいことが多いので、「確認→次の案」のサイクルでお願いします。

3. 不具合が出たとき、状況を推測だけで決めないでください。  
   - エラー内容、ログ、スクショ、実際の画面など「事実」を必ず確認した上で判断してください。
   - 「たぶんこうなっているはず」といった類推は極力しないでください。

4. コード修正は、できるだけ「全体」または「関数やブロック単位」で提案してください。  
   - 1行だけの修正指示（「〇行目を〇〇に変えて」など）は、間違いが増えるので最小限にしてください。
   - 可能なら「この関数全体を以下に差し替えてください」という形でお願いします。

5. 目の前の不具合を“小手先のコード変更”だけで片付けようとしないでください。  
   - Registro500 Giappone プロジェクト全体の目的・構成を踏まえて、
     長期的に見て無理のない修正・設計になっているかを一緒に検討してください。

6. 回答は必ず、このチャットの履歴と、私が貼った最新コード・説明を踏まえてください。  
   - 過去の指示や前提条件と矛盾しないか、チェックした上で回答してください。

7. 私がスクショをアップしたときは、そのスクショを隅から隅までよく見てください。  
   - 画面上部のパス（例：gas/sites/main.gs）、ボタンの位置、エラー文など、
     細部をきちんと読んだうえで判断・指示してください。
