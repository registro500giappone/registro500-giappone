## 1. 何が起きたか（2026-08-09 実測）

**歴代トップの車載手帳が書かれたのに、「みんなの車載手帳」の一覧に出ていない。**

| 項目 | 実測値 |
|---|---|
| 手帳ID | `c984e2d3-9e6b-49fe-9b17-fae3861c9a6c` |
| 記入者 | `yoda7jp@gmail.com`（auth.users `ffdb986d-…`） |
| アカウント作成 | 2026-08-09 06:45 UTC（＝15:45 JST）※このサイト初利用 |
| 手帳の保存 | 06:51 UTC（作成の6分後） |
| 記入項目数 | **66**（有効67項目中） |
| マスター該当 | **49/50** ← 従来トップのMEXさん46を上回る |
| 安全・救援 | **4/4** |
| 公開設定 | `is_public = true`（ご本人がオンのまま保存） |
| `vehicle_id` | **null** |
| `cars` の登録 | **なし**（`owner_user_id` 一致0件・`owner_email` 一致も0件） |

- 公開手帳は11件あるが、一覧を作る `equipment_public_list()` が返すのは **10件**。この1件だけが落ちている。
- 原因は不具合ではなく仕様の穴。一覧の1行は「車両の写真・ハンドルネーム・車種」で構成されるため、**登録車両に紐づかない手帳は行を組み立てられない**（HANDOFF §51「既知の小さい穴」がそのまま現実になった）。
- しかも保存時の確認ダイアログは「あなたの車両ページと**公開一覧に表示され**、誰でも閲覧できます」と表示していた。**この方には果たされていない約束**だった。→ 文言と案内は 2026-08-09 に修正済み（後述）。

### つまり、この方は

サイトに愛車を登録しないまま、車載手帳だけを（それも67項目中66項目まで）書いてくださった**初めてのケース**。
空冷Fiatにかなり手を入れている方である可能性が高い。**愛車を登録していただければ、車載マエストロ第2号**になる。
