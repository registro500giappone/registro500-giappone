電装トラブルの旅手帳第11回

ワイパーが動かない

雨が降りだしてスイッチを入れたのに、ワイパーが動かない。あるいは切ったのに止まらない。500 のワイパーは、スイッチとモーターのあいだに線が2本あります。片方は回すための線、もう片方は「止めるための線」です。この2本を分けて見ると、動かないときと止まらないときで、疑う場所がはっきり分かれます。

このストーリーは FIAT 500（D・F・L・R型） の話です。配線は500の原典から起こしています。

スイッチを入れても2本とも動かない——というのがこのページの症状です。キーは回してください。500 のワイパーはキーを回さないと動きません（ヘッドライトや車幅灯とは、そこが違います）。⭐この2本のワイパーは、1つのモーターが動かしています。だから「片方だけ動かない」なら電気の話ではなく、リンク（腕をつないでいる金具）の話です。

⚠️ワイパーが動かない車で、雨の中を走らないでください。空冷500 のフロントガラスは小さく、曇りやすく、拭けないと本当に前が見えません。降りだしたら止まって待つ——それが一番安全です。
⚠️配線をいじる前はバッテリーのマイナス（−）端子を外してください。この系統はキーOFFで死にますが、同じヒューズ箱の隣には、キーを切っても生きている線があります（ホーンとルームランプ）。
⚠️ヒューズを「太いもの」に替えないでください。この回路を守っているヒューズは、ブレーキランプとウインカーも一緒に受け持っています。容量を上げると、守るはずの細い配線のほうが先に焼けます。
しくみ

スイッチを切っても、モーターには電気が来ている

キーを回すと、ヒューズ F2 の先に電気が届きます。ここからワイパースイッチへ1本——ここまでは、ほかのストーリーと同じ形です。⭐ところが500 は、もう1本を「スイッチを通さずに」モーターへ直接つないでいます。だからスイッチを切っていても、キーが入っている間はモーターの端子に電気が来たままです。

これは配線の間違いではありません。ワイパーを切ったとき、腕を立てたまま止めずに、フロントガラスの下まで戻してから止めるための線です。切ったあとに動くための電気が要るので、スイッチの外から引いてあるのです。

絵の中のスイッチを、入と切に押してみてください。キーはONのままです。切ったときに、いちばん左を降りている1本（青／黒）の色が消えないことを見てください。

⚠️この絵は、切ったあとに定位置まで戻る動きそのものは持っていません。その動きはモーターの中で軸が回るのに合わせて開いたり閉じたりする接点が作っていますが、原典の配線図はモーターの中を描いていません（4本の端子が出た箱として描かれているだけです）。だからこの絵では、その2本は「つながっている」ことだけを表しています——黄色い粒も流していません。⭐ただし、その中がどうなっているかは分かっています——このあと開けます。

回している線は、2本のうち1本だけ

スイッチの箱の真下を降りている2本を、分けて覚えてください。⚠️絵のいちばん左を降りている青／黒は、これとは別の線です（スイッチを通らない1本——上で見たものです）。

  • 真下の右の1本（青）＝回すための線。スイッチを入れると、ここを通ってモーターへ電気が行きます。⭐動かないときに疑うのは、こちらです。
  • 真下の左の1本（青／白）＝止めるための線。スイッチを切ったあと、定位置まで戻すのに使われます。⭐入にしているあいだは、この線が外れていてもワイパーは動きます——だから「動くけれど、止めると変なところで止まる」という症状になります。

⚠️この絵では、青／白の1本はいつも薄いままです。この線が働くのはモーターの中の接点が閉じているあいだだけで、その接点を、この絵は持っていないからです（そのぶん、次の節で中を開けます）。薄い＝断線している、ではありません。

⚠️線の色は型式で1本だけ違います。この「止めるための線」が、D型では BIANCO（白）、F型・L型・R型では AZZURRO-BIANCO（青／白）です。⭐F型・L型・R型どうしは、結線（どこからどこへ行くか）もまったく同じでした。⚠️D型だけは、スイッチのつながり方が違います——このあと「D型だけは、自分で戻す」で説明します。

モーターの中では、なにが起きているか

ここから先は、配線図ではなく、純正の整備解説書に描かれている中身です。⭐配線図が「どことどこがつながっているか」を教えるのに対して、整備解説書は「どう動くか」を教えてくれます——同じ車の、別の本です。

ワイパーモーターの中には、巻線が3つと、軸の回転に合わせて開いたり閉じたりする接点が1つ入っています。

モーターの中（模式図）。上の4本が、いままで見てきた4本です。⭐いちばん左を降りてきた1本（青／黒）は、C から入って、この接点 D を通ります——だから「切っても電気が来ている」ことに意味があるのです。

  • A＝直巻線。INT から入って電機子を回します。⭐「入」にしたとき、ワイパーを動かしているのはこれです。
  • B＝分巻線。電機子と並んで入っていて、回りかたを支えます。
  • S＝補助巻線。⭐巻数が少なくて、線が太い——整備解説書がわざわざそう書いています。ゆっくり、力強く回すための巻線で、戻すときにしか働きません。
  • D＝カム接点。C から来た電気を、腕が定位置に来るまでのあいだだけ通します。

カムが、止める

この接点 D を開け閉めしているのは、減速ギヤのピニオンに固定された、扇形の部品です。⭐整備解説書は「回路図では、簡略化してカムとして描いた」と自分で断っています——実物はカムというより、歯車に付いた出っ張りです。

左＝回っているあいだ。セグメントは接点から離れていて、接点は閉じたままです。右＝腕が定位置まで来た瞬間。セグメントが接点を押し上げて開き、電気が切れて止まります。

つなげると、こうなります。スイッチを切る → スイッチの中でつながりが入れ替わってモーターの F 端子がアースに落ちる → 補助巻線 S が働きはじめる → モーターはゆっくり、力強く回りながら、C 端子から来ている電気で動き続ける → 定位置でセグメントが接点 D を開く → 止まる。⭐これが「切ったら、フロントガラスの下まで戻ってから止まる」の中身です。

D型だけは、自分で戻す

⚠️ここまでは F型・L型・R型の話です。⭐D型のワイパースイッチは、上下に3つの位置を持っています。

  • 上＝運転。ワイパーが動きます。
  • 中＝切。⚠️その場ですぐ止まります——腕が立ったままの位置でも、そこで止まります。
  • 下＝戻し。⭐ここへ倒しているあいだだけ、いま見た補助巻線 S の回路がつながって、腕が定位置まで戻ります。戻ったら、手を放します（ばねで自動的に「切」へ返ります）。

配線図の上では、この違いはスイッチに入る線の数として現れています。⭐D型のスイッチには、モーターの C 端子へ行く線がつながっています——だから「下へ倒したときだけ」電気を送れるのです。F型・L型・R型のスイッチにはその端子がなく、C 端子はヒューズから直接つながっています——だから切れば勝手に戻るかわりに、キーが入っているあいだは、いつも電気が来ているのです。

⚠️この絵は F型・L型・R型のつなぎ方で描いてあります。⭐D型にお乗りの方は、「切ってもモーターに電気が来ている」のところだけ読み替えてください——D型では、レバーを下へ倒しているあいだだけ来ます。それ以外（動かないときにどこを疑うか、ヒューズ F2 が同じであること、アースの話、モーターの中身）は4型式とも同じです。

ヒューズ F2 の、3人目

ワイパーを守っているヒューズ F2 は、ブレーキランプ（第7回）とウインカー（第10回）と同じ1本です。⭐この3つが同時に死んだら、電球が3つ同時に切れたのではなく、ヒューズ1本で説明が付きます。

逆に、ホーンは鳴ります——あれは別のヒューズ（F1）の先だからです。エンジンもかかります。点火の線は、このヒューズの手前で分かれているからです（第6回）。⭐「エンジンはかかるのに、ワイパーもブレーキランプもウインカーも死んでいる」——これが F2 の顔つきです。

キーがOFF＝これは故障ではない

スイッチを入れたまま、キーがOFFの状態です。動かないのが正常です。500 のワイパーはヒューズ F2 の先にいて、キーを回さないと動きません。⭐キーを回してからもう一度——これが最初に潰す迷い道です。

F2 が切れた

ヒューズが切れると、モーターへ行く2本とも、いっぺんに死にます。⭐このとき、ブレーキランプもウインカーも一緒に死んでいます。逆に言えば、ブレーキを踏んでもらってランプが点くなら、ヒューズ F2 は無事です——車から降りずに、ヒューズを見る前に確かめられます。

スイッチからモーターへの、1本が外れた

スイッチは入っていて、ヒューズも生きているのに動かない場面です。回すための1本（青）が外れています。⭐このとき、いちばん左の1本（青／黒）にはまだ色が残っています——モーターの端子まで電気が来ていることと、モーターが回ることは別だからです。

アースが外れた＝電気は来ているのに、回らない

モーターのアース（帰り道）が外れた場面です。⭐モーターの端子までは、電気がちゃんと来ています。それでも回りません——電気は行って帰ってこないと仕事をしないからです。ワイパーモーターは車体にボルトで留まっているだけのことが多く、その留めねじの錆や塗装が、そのままアース不良になります。

もう一つの症状＝切ったのに止まらない

スイッチは切にしてあるのに、接点が戻っていない場面です。モーターは回り続けます。⭐キーを抜けば止まります——このページのいちばん下の検算にある「固着のままキーを抜く」の行がそれです。

⚠️「止まらない」には、この絵で言えないもう一つの原因があります。それがさきほど見たカム接点 D です。ここの接点が汚れて電気を通さなくなると定位置まで戻らずに途中で止まり、逆にセグメントが接点を開けなくなるとゆっくり回り続けます——⭐整備解説書が、この2つを故障例としてそのまま挙げています。この絵では、スイッチの接点が閉じたままかどうかまでしか見分けられません。⛔回り続けている様子を眺めただけでは、スイッチの側なのかモーターの中なのかは決まりません——どちらも同じ「止まらない」に見えます。
⭐切り分けるなら、スイッチのほうから確かめてください。スイッチはこの絵の中にいる部品です。外して「切」にしたときに端子の間がつながったままかどうかを見れば、そこで決着します。スイッチが正常なら、疑いはこの絵の外——モーターの中へ移ります。

⚠️⭐腕を外したら、戻すときの締めが効いてきます。純正の整備解説書は「腕の固定ナットが緩むとモーターが焼ける」とはっきり書いています。緩んだ腕は途中で滑って止まり、モーターだけが力いっぱい回り続けるからです——拭き幅がだんだん狭くなってきたのは、その入口かもしれません。気づいたら締める。それだけでモーターが1つ助かります。

直った

スイッチを入れて、黄色い点がヒューズ →スイッチ →モーター →車体アースと一周しています。⭐いちばん左の1本（青／黒）にも色が来ていることを、もう一度見てください。切ったとき、モーターはこの線から電気をもらって、定位置まで戻ります。

図の動き・色はすべて計算結果で、絵に合わせて数字を作っていません。 ⭐ヒューズ F2 の先から、スイッチを通らずにモーターへ直接1本行っています（原典で、モーターの端子とスイッチの端子とヒューズの負荷側に、同じ色の線がつながっています）。だから切っていてもモーターには電気が来ています。
⭐スイッチとモーターのあいだは2本で、回すのはそのうち1本だけです（原典で、F型・L型・R型のスイッチから出る線は4本＝給電・アース・モーターへ2本）。
⭐モーターの中身（巻線 A・B・S と、カム接点 D）は、純正の整備解説書に載っている回路図と本文から起こしました——配線図のほうは、モーターを4本の端子が出た箱としか描いていません。同じ本に、動く速さは毎分50〜60往復、消費電流は最大 1.7〜1.8A とあります。
⚠️線の色は型式で1本だけ違います。「止めるための線」が D型では BIANCO（白）、F型・L型・R型では AZZURRO-BIANCO（青／白）。⚠️R型の色は、部品商が配っている配線図で確かめています（純正の取扱説明書ではありません）。⚠️つなぎ方も、D型だけ違います——D型のスイッチにはモーターの C 端子へ行く線があり、上の「D型だけは、自分で戻す」で説明したとおりです。F型・L型・R型どうしは、色も結線もまったく同じでした。
⚠️部品の番号は、本ごとに違います。この絵にあえて番号を書かなかったのはそのためです。⛔同じ D型でも、取扱説明書の巻末の凡例と、部品商が配っている配線図とで番号が食い違います。番号だけで突き合わせず、端子の名前（31・C・F・INT）と、線の色で確かめてください——⭐こちらは4型式で共通です。
⚠️この絵が持っていないもの：
①カム接点 D の、開け閉めそのもの＝上で図にしたとおり、軸が回るのに合わせて開いたり閉じたりします。この絵は線がつながっているかどうかしか見ておらず、軸がいまどこにいるかを持っていません。だから C と F の2本は「つながっている」ことしか表しておらず、止まる位置がおかしい症状は、この絵の外です。
②スイッチの中で接点がどう組み変わるか＝原典はスイッチの中を描いてはいますが、拡大しても組み合わせまでは読み取れません。だからこの絵は、スイッチを「入で1組がつながる／切で離れる」とだけ扱っています。
③速さ・重さ＝線がつながっているかどうかしか見ていないので、電圧の落ち方や、ガラスの摩擦は表せません。
④間欠（インターバル）＝原典の取扱説明書にも、純正の整備解説書にも、間欠についての記述がありません。⭐F型・L型・R型のスイッチは入と切の2つ、D型は運転・切・戻しの3つで、どちらにも間欠はありません。この絵は F型・L型・R型のほうで描いています。
⚠️スイッチ自身のアース線と、止めるための2本には、黄色い粒を流していません。この絵は部品の中の導通を持たないので、その線については「つながっている」ことしか言えず、流れているとは言えないからです。線が薄くなっていなければ、つながっています。
