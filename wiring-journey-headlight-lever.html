電装トラブルの旅手帳第8回 別冊

コラムレバーの中身

ステアリングの下から生えている、あの下側のコラムレバーの話です。第8回では「例外がひとつある」と一言で済ませたパッシングを、ここで最後まで開けます。

この別冊が立っている足場。 ここに書いたことは500D の純正の資料——取扱説明書と、整備解説書の「操作・監視の部品」の章——から読み取ったものです。⚠️F型・L型・R型のコラムスイッチは、部品としては別物です（部品商の適合表では別番号で、線の本数も違います）。働きは同じですが、中の作りが同じだとは書けません。この別冊は「D型ではこうなっている」という話として読んでください。

コラムレバーから出ている線は7本ある

配線図でこのコラムレバーをたどると、束から7本が出ています。4本が入口・3本が出口です。入口が4本もあるのが、この部品のいちばんの特徴です。

端子被覆の色向き相手
C白（BIANCO）入口ダッシュのライトスイッチから。整備解説書は「この切替器は計器盤の主スイッチから給電される」と書いています
INT黒（NERO）入口常時電源から。⭐ライトスイッチを通っていません
30/2ピンク（ROSA）入口ヒューズ F6 の先から
30/3茶（MARRONE）入口ヒューズ F5 の先から
56b灰（GRIGIO）出口ロービームへ（この先でヒューズ F3・F4 に分かれます）
56/a2緑（VERDE）出口右のハイビームへ
56/a1緑＋黒（VERDE E NERO）出口左のハイビームへ（ハイビーム表示灯もここです）

端子名は D 型の純正配線図の表記そのままです。色名も原典のイタリア語表記に日本語を添えてあります。

この表だけで、第8回で出てきた「たすき掛け」の理由が分かります。⭐ハイビームの電気は、車幅灯のヒューズ（F5・F6）の先から入ってきているのです。30/3（F5から）が左のハイビームへ、30/2（F6から）が右のハイビームへ。だから片方のヒューズが切れると「片側のハイビーム」と「反対側の車幅灯」が一緒に消える——第8回と第9回で見たあの組み合わせは、ここで作られています。

いっぽうロービームは違います。ロービームの電気は C——つまりダッシュのライトスイッチから直に入ってきて、コラムレバーの中を通って 56b から出ていきます。ヒューズはその先（F3・F4）にあります。

位置ごとに、中で何がつながるか

コラムレバーは下へ倒すほど段が進みます。取扱説明書が書いている「その位置で点いているもの」を、上の端子表と重ねるとこうなります。

コラムレバー点くもの（取説）中でつながる線
Iナンバー灯・車幅灯・テールランプヘッドライトへは何も出ません
II＋ロービームC → 56b
III＋ハイビーム30/3 → 56/a1（左）と 30/2 → 56/a2（右）
手前へ引くロービームが光る（パッシング）INT → 56b

⚠️「中でつながる線」は、端子の名前と行き先から組み立てた読み方です。原典の配線図はコラムレバーの中を描いていません——描かれているのは、7本がどこから来てどこへ行くかまでです。

パッシングだけ、電気の入口が違う

表をもう一度見てください。II のロービームは C から、パッシングのロービームは INT から——同じ電球を光らせるのに、電気の入口が2つあるのです。

これが、ライトスイッチを切ったままでもパッシングができる理由です。C はライトスイッチの先ですが、INT はライトスイッチを通っていません。ドイツの 500 乗りの集まりでは、コラムスイッチを交換した人がテスターを当てて「パッシングで導通するのは 56b と INT の2本」と報告していて、この読み方と一致します。

切り分けに使えます ロービームが点かない。パッシングは光る。——だとすれば、電球もアースも 56b の線も生きていることになります（パッシングはその同じ道を通っています）。疑うのはライトスイッチから C までの側です。
逆にパッシングだけが光らないなら、INT の線か、コラムレバーの中のパッシングの仕掛け——次の節に出てくる押しピンです。

⚠️ 500D の取扱説明書は「II を除くすべての位置で手前へ引ける」と書いています。整備解説書を読むと、II の位置にはドラムの接触面が無く、押しピンを押せません——機構として除かれているのであって、ロービームが点いていて変化が見えないから、ではありません。⚠️ただし F型・L型の取説にはこの但し書きがなく、実車のオーナーの証言とも食い違います。自分の車で確かめてください。

中はどうなっているか

整備解説書が、この部品の中身を一段落だけ説明しています。⭐回るドラムと、樹脂の板に埋め込まれた固定接点——そしてパッシングだけは、まったく別の仕掛けです。

1 回転ドラム。コラムレバーを倒すと、この筒が回ります。
2 バネで押しつけられた接点ブリッジ。ドラムに載っていて、回った先で固定接点に橋を架けます。
3 固定接点。樹脂の絶縁板に埋め込まれていて、ここから外の線につながります。
4 ⭐パッシングだけの別の仕掛け。ドラムの側面のカム面が押しピンを押し、その下の弾性接点を閉じます。段を選ぶ機構ではなく、押している間だけ閉じる機構です。

⚠️ この図は作りの説明です。整備解説書はこの構造を文章で説明していますが、どの接点がどの端子かまでは書いていません。だから図の中の接点には端子名を振っていません（下に書いた INT・56b は、パッシングの仕掛けが結んでいる2本というだけです）。

壊れ方は、原典に5つ書いてある

整備解説書の「外部照明の切替器」の項には、症状と原因が5つ並んでいます。⚠️そして5つとも、結びの文は同じです——「切替器一式を交換すること」。⭐この部品は、原典が最初から「直さずに替える物」として扱っています。

症状原典が挙げる原因
パッシングのとき、接点が不規則にしかつながらないドラムと座のガタが大きい／接点ブリッジや固定接点の摩耗／接点ブリッジの固着／押しバネの折損・へたり
⭐コラムレバーをどの位置にしてもロービームが点きっぱなし押しピンが戻らない／弾性接点のへたり
パッシングをしても光らない可動接点の折損／接点の酸化／押しピンの摩耗／ドラムのカム面の摩耗／固定接点側の配線の緩み
コラムレバーの節度（カチッという手ごたえ）が弱い・出ないばね仕掛けのボールが座から出すぎている
コラムレバーが重い・動かない同上

2つめが分かりやすい例です。コラムレバーをどの位置にしてもロービームが消えない——配線のどこかがショートしているように見えますが、原典はまず押しピンが戻っていないことを疑えと言っています。⭐パッシングの仕掛けが「押しっぱなし」になっている状態です。INT はライトスイッチを通っていないので、この状態ならライトスイッチを切っても消えないはずです。

この別冊の外にあるもの
①F型・L型・R型のコラムスイッチの中身＝別部品なので、ここに書いた作りをそのまま当てられません。
②ウインカーのレバー＝上側のレバーは別の切替器で、これも中身が違います。
③端子と接点の対応＝どの固定接点がどの端子かは、原典のどこにも書かれていません。
④実車のどこにあるか＝この系統の部品はまだ実測されていないので、位置の図は付けていません。
