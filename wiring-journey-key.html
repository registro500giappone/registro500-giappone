電装トラブルの旅手帳第4回

キーを回しても何も点かない

キーをONにしても、計器盤の警告灯が1つも点かない。電気の通り道を1本の絵で追って、どこで止まっているかを絞り込みます。

このストーリーは FIAT 500（D・F・L・R型） の話です。配線は500の原典から起こしています。

キーをONにしたのに、GENERAT.（充電）も OLIO（油圧）も点かない。これがこのページの症状です。

テスターを出す前に、1つだけ スターターレバーを引いて、セルが回るかどうかを確かめてください。それだけで容疑者が半分に減ります（下の絞り込みの表の①）。
バッテリーのプラス（＋）端子に当てた工具の先が車体に触れると、その瞬間に工具が焼けるほどの電流が流れます。この太い線にヒューズはありません。端子や太い線を触るなら、先にバッテリーのマイナス（−）端子を外してください。
⚠️原因を探しているあいだ、キーをONにしたまま放置しないでください。点火ポイントが閉じた位置で止まっていれば、イグニッションコイルとポイントに電気が流れ続けて熱を持ちます（開いた位置で止まっていれば流れません）。どちらで止まっているかは外から見えませんし、そのあいだバッテリーも減り続けます。車から離れるときはキーをOFFに戻してください。
しくみ

キーONで警告灯が点くまでに、電気は車を1往復している

このあと「太い線」と書くのは、原典の配線図が、この電源まわりだけをほかより太く描き分けていることを指しています。ヒューズを通らず、大きな電流が流れる区間です。

  1. バッテリーのプラス端子から出た太い赤線は、途中で2つに分かれます。ここはネジ止めの端子ではなく線どうしのつなぎ目です。まっすぐ下りる先はセルモーターの上の接点（第3回）、このストーリーが追うのはもう一方です。
  2. 分かれ道から太い茶線が車の後ろへ回り、レギュレータの端子30に着きます。そこから太い赤線が同じ30端子を出て車の前へ戻ります——入る線も出る線も、ネジ1本の同じ端子です。
  3. ⚠️オルタネーターに換えた車には、この「レギュレータの端子30」がありません。同じ役割——バッテリーからの太線が集まって、キーへ戻っていく折り返し点——を、換装車ではオルタネーターの B+ 端子が持っています。測る場所はそこに読み替えてください（どこで集めるかは施工の仕方で違うので、自分の車の太い線を目で追うのが確実です）。「いったん車の後ろまで行って戻ってくる」という道の形は、換装車でも変わりません。この折り返し点が換装車でどうなるかは、第1回の別冊「チャージランプが消えない・オルタ換装車」に絵があります。
  4. 戻った先はヒューズ箱の30（ヒューズF1の電源側）。ここから太い赤線がキースイッチの30へ分かれます。
  5. キーを回すと30 と 15/54 がつながり、水色の線1本で計器盤の INTER（＝2つの警告灯を養う1本の給電レール。以下この名前で呼びます）へ。ここから2つの警告灯に分かれ、それぞれ端子51（GENERAT.）と端子0（OLIO）から落ちていきます。

同じ「30」が何か所にも出てきます。これは部品の名前ではなく端子の役目を表す番号で、30＝キーの位置に関係なく常に電気が来ている端子、15/54＝キーを回したときに電気が出ていく端子という決まりです（原典の配線図もこの番号で書かれています）。だから図に3つ出てくる30は、ぜんぶ同じ1本の道の上です。上の絵では、原典に番号のある所だけに札を付けてあります——札の無いところは端子ではありません。

線の色は実車の被覆の色そのまま（ROSSO=赤・MARRONE=茶・AZZURRO=水色・VERDE=緑・GRIGIO=灰）。黄色い点＝いま電気が流れている所。薄い線＝電気が来ていない所。計器盤の中だけ細い明るい線で描いてあるのは、原典の図から内部の結線を読み切れていない（推定）ためで、確かな線と見分けが付くようにしています。

よくある疑問 「エンジンが掛かっているときに消えているのは、故障ではありません。」むしろ正常です。GENERAT. は発電が始まると消え、OLIO は油圧が上がると消えます（それぞれ第1回・第2回のストーリー）。このページが扱うのはキーONでエンジンが止まっているのに点かない場合だけです。エンジンが掛かる車なら、いちばん確実な確認は「キーONで点いて、掛けると消える」——この2段階です。
なぜ絞り込めるのか

2つとも消えているなら、犯人は「2つに共通する部分」にしかいない

原典の配線図では、計器盤の警告灯はどれも同じ水色の線1本（INTER）で受けていて、違うのは落とし先だけです。だから：

  • 2つとも消えた → 共通部分（バッテリー〜キー〜INTER、そして帰り道のアース）が怪しい。
  • 片方だけ消えた → 共通部分は無実。怪しいのはその警告灯の落とし先だけ（＝第1回・第2回のストーリー）。

上は端子0から落ちる灰色の線だけが切れたところ（×印）。OLIO は消えましたが、GENERAT. は点いたままです——共通部分が生きている証拠。この1枚が、上の絞り込みの根拠になっています。

異常のとき ①

行きの道が1本切れた＝2つとも消える

上の絵はキースイッチへ行く赤線が外れたところ（赤い札の高さ）。その線から下が丸ごと薄くなり、2つとも消えました。①でセルが回ったのなら、切れている場所の候補は囲いの中だけです：

  1. バッテリー上がり・端子の緩み（いちばん多い）。ただしこれはセルも回らなくなるので、表の①で割れます。
  2. 車の後ろへ行く太線／戻ってくる太線と、その端子の外れ・緩み。レギュレータの30に集まっているので、ここが緩むと前の電気が全部止まります。
  3. キースイッチそのもの（接点の摩耗・キーシリンダーの空回り）。
  4. 計器盤へ行く水色の線の断線・コネクタ抜け。

ヒューズを疑いたくなりますが、この症状ではヒューズを見ても直りません。キースイッチへの赤線はヒューズの電源側から分かれています（絵のとおり、ヒューズの中を通っていません）。検算でも「F1が切れていても警告灯は点く」ことを確かめてあります。第1回（チャージランプ）とまったく同じ理由です。

異常のとき ②

帰り道が切れた＝線には12Vが来ているのに、何も点かない

こちらはバッテリーのマイナス端子が外れたところ。よく見てください——絵の線には色が付いたままです。つまり12Vはちゃんと届いている。それでも1つも点きません。

電気は一周の輪でしか流れません。行きの道が生きていても、バッテリーのマイナス端子へ戻る道が無ければ、輪は閉じません。テスターをプラス側に当てると元気に12Vが出るので、「電気は来ているのに動かない」といういちばん紛らわしい形になります。この帰り道そのものを主役にしたストーリーが第5回です。

絞り込み

セルを回す。それだけで上下が割れる

手順結果意味
① スターターレバーを引く（キーの位置は関係ありません）セルが回るバッテリー・プラスの太線・アースの帰り道は生きている（セルの輪はそこを通るため）。容疑者は分かれ道から計器盤まで → ②へ
回らない容疑者はバッテリー本体・プラス端子・マイナス端子。警告灯が点かないのは結果であって、警告灯の側は無実 → 第3回「セルが回らない」へ
② キーONでキースイッチの 15/54 端子にテスターを当てる12V が出るキースイッチまでは無実。残るのは水色の線1本と計器盤の中（INTER と電球）→ ④へ
0Vキースイッチか、その手前 → ③へ
③ 同じく30 端子にテスターを当てる（キーの位置は問わない）12V が出るキースイッチそのものが犯人（接点が渡っていない）
0V30 の道＝太い赤線・太い茶線・レギュレータの端子30（換装車はオルタの B+）・端子の締まり。車の後ろ側まで追う必要があります
④ 電球が2つ同時に切れることは、まずありません②で12Vが来ていて2つとも消えているなら、水色の線か計器盤の中を疑います。片方だけなら共通部分は無実です

①〜③の期待値は、手で書いた数字ではなく、この絵と同じ計算（通り道の到達性）から出ています。①でセルを先に回すのは、それが「バッテリーと両方の端子」を一度に確かめられる唯一の操作だからです＝セルの輪と警告灯の輪が共有しているのは、そこだけです。

実車ではここ

キーに来る電気は、いったん車の後ろまで行って戻ってくる

●バッテリーは車の前（トランクの中）、●レギュレータは後ろ（エンジンルーム）、●ヒューズ箱と●キーと●メーターはまた前。絵の上では一直線に見えた道が、実車では車を1往復しています。だから「後ろで端子が1つ緩んだせいで、前の計器盤が全部死ぬ」ことが起こります。

直ると

端子を締め直した。2つとも点いた。

バッテリーから出た電気が車の後ろを回って前へ戻り、キーを通って計器盤の INTER まで届き、2つの警告灯がそれぞれ端子51・端子0へ落ちて輪が閉じました。次はエンジンを掛けてください。2つとも消えれば、発電も油圧も正常です。

この先のストーリー → セルが回らない（このストーリーの対・容疑者は分かれ道より下）／ チャージランプが消えない（GENERAT. の落とし先）／ 油圧警告灯が消えない（OLIO の落とし先）
検算（この図が原典・実車の挙動と一致していることの自動確認）

期待値は原典（純正取扱説明書の配線図）と実車の挙動から先に書いたもので、計算結果を写していません。1件でも✗なら図のデータの側が誤りです。「↑同じ場面の…」の行は、同じ1つの場面を別の警告灯・別の負荷から読んだもの＝2つの警告灯が揃って消えるのか、片方だけなのかを確かめています。

図の点灯・色はすべて計算結果で、絵に合わせて数字を作っていません。 ⚠️「線が外れた」の絵は、接点の位置ではなく線が1本無い状態として計算しています。
⚠️この計算の限界：電気の「細さ」（接触抵抗による電圧降下）を持っていません。端子が緩んで電気が細くなっただけの状態は、この絵では「つながっている」と出ます。警告灯はごく小さな電流しか使わないため、細くなっても点いてしまうことがあり——その場合はセルの方に先に症状が出ます（第3回）。
⚠️計器盤の内部（給電レール INTER と電球の並び）は原典の図から読み切れていない推定です。絵の中でも細い内部線として描き分けています。
