# エンジン手動トレース作業ガイド

FIAT 500配線ビューア（`wiring/index.html`）に、エンジンの手描き線画を追加するための作業手順です。
Inkscapeというフリーの線画・図形エディタを使い、実写真をなぞって線画（SVG）を作ります。
**Inkscapeを触ったことがない前提**で、必要な操作だけをかいつまんで説明します。

---

## 0. できあがるもの

`wiring/tools/trace/engine/` に、3方向ぶんのテンプレートSVGが用意してあります。

| ファイル | アングル | 元写真 |
|---|---|---|
| `side_template.svg` | 左側面 | 01_BEST_side_fdricambi.jpg |
| `rear_template.svg` | 後面 | 02_front_fdricambi.jpg |
| `flywheel_template.svg` | 右斜め（フライホイール側） | 03_other_fdricambi.jpg |

各テンプレートは3枚のレイヤー（層）を重ねた構造になっています。

1. **reference層**（一番下）: 元写真がうっすら透けて見える下敷き。ロック済みで動かせません。
2. **edge_hint層**（真ん中）: パソコンが自動抽出した輪郭線のガイド（グレーの薄い線）。同じくロック済み。
3. **trace層**（一番上）: あなたが実際に線を描き込む層。今は空です。

この3層構造のおかげで、下敷きの写真を消したり動かしたりしてしまう心配がなく、
「edge_hintのグレー線をなぞる」「写真を見て必要な線を足す」の両方がやりやすくなっています。

---

## 1. Inkscapeのインストール

1. 公式サイト https://inkscape.org/ を開く
2. 「Download」→ Windows版（.msi または .exe）をダウンロード
3. ダウンロードしたインストーラーを実行し、案内に従ってインストール（無料・アカウント登録不要）
4. インストール後、スタートメニューから「Inkscape」を起動できることを確認

バージョンは1.0以降であれば基本操作に大きな違いはありません。

---

## 2. テンプレートの開き方

1. Inkscapeを起動
2. メニュー「ファイル」→「開く」（または `Ctrl+O`）
3. `wiring/tools/trace/engine/side_template.svg` を選択して開く
   - まずは側面（side）から始めるのがおすすめです。パーツが一番判別しやすいアングルです。

開くと、うっすら透けたエンジン写真の上に、グレーの輪郭線が薄く重なって見えるはずです。

### レイヤーパネルの出し方

- メニュー「レイヤー」→「レイヤーと目次...」（`Shift+Ctrl+L`）でレイヤーパネルが開きます
- パネルには `reference` / `edge_hint` / `trace` の3行が並んでいます
- 各行には以下のアイコンがあります
  - **目のアイコン**: クリックで表示/非表示を切り替え（写真が邪魔なときは`reference`を非表示に、グレー線が邪魔なときは`edge_hint`を非表示に）
  - **鍵のアイコン**: ロック状態を示す（`reference`と`edge_hint`は最初からロック済み＝誤って動かない）
  - **不透明度スライダー**: 選択中のレイヤーの下敷きの濃さを調整できる（写真をもっと薄くしたい/濃くしたいときに使う）
- 一番上の`trace`が選択されている（＝アクティブレイヤー）状態で開かれます。新しく描いた線は自動的にこの層に入ります

---

## 3. 推奨ワークフロー

いきなり細部を描こうとせず、次の順番で進めるとスムーズです。

### ① まずシルエット（外周）から

エンジン全体の外形の輪郭を、大まかな1本の線でぐるっと囲みます。全体のプロポーションが最初に決まるので、後の作業がやりやすくなります。

### ② ペンツール(B)で直線的に打ち、あとでノード編集(N)で曲線に

1. キーボードの `B` キーでペンツールに切り替える
2. 写真の輪郭に沿って、**クリックで点を置いていく**（ドラッグせず、クリックだけでOK）。この時点ではカクカクした直線の集まりになります
3. 一周したら最初の点をクリックして閉じる（または `Enter` で確定）
4. キーボードの `N` キーでノード編集ツールに切り替える
5. 直線になっている部分をダブルクリックすると、その線分に「ハンドル」が出て曲線にできます。ハンドルをドラッグして写真のカーブに合わせます

最初から曲線ツールで滑らかに描こうとすると難しいので、**まず直線でおおまかに、あとで曲げる**という順番が描きやすいです。

### ③ ノイズ・反射・陰影は無視する

写真には金属の反射、汚れ、影が写り込んでいますが、これらは線として拾わないでください。
拾うべきなのは以下だけです。

- パーツとパーツの**境界線**（例: エンジンブロックとファンカバーの継ぎ目）
- ボルト・プーリー・ホースなど**特徴的な形状の輪郭**
- 配管・配線が這っている**大まかな経路**

「edge_hint層」の自動抽出線は、反射や汚れも拾ってしまってノイズが多い部分があります（特にファン周辺）。これは目安に過ぎないので、写真を見ながら「本当にここに境界があるか」を自分の目で判断してください。

## 4. ショートカット早見表

| キー操作 | 内容 |
|---|---|
| `B` | ペンツール（ベジェ/直線）に切り替え |
| `N` | ノード編集ツールに切り替え |
| `S` | 選択ツールに切り替え |
| `Ctrl` + マウスホイール | ズームイン/アウト |
| `スペース` を押しながらドラッグ | 画面のパン（移動） |
| `3` | 選択オブジェクトにズームして表示 |
| `5` | ページ全体を画面に合わせる |
| `Ctrl+Z` | 元に戻す（アンドゥ） |
| `Ctrl+Shift+Z` | やり直し（リドゥ） |
| `Ctrl+S` | 保存 |
| `Delete` | 選択中のノード/パスを削除 |
| `Esc` | 描画中のパスをキャンセル |

## 5. 作業量の目安

- 1アングルあたり **50〜150本程度のパス**（線）が目安です。細かいボルト1本1本まで拾う必要はありません
- 初回は **1時間のタイムボックス**をおすすめします。完成度よりも「どこまでできるか」の手応え確認を優先してください。1時間でどのくらい進むか分かれば、残り2アングルの所要時間の見積もりもできます
- 疲れたら`Ctrl+S`で保存して中断し、いつでも同じファイルを開いて続きから作業できます

## 6. （オプション）パス→ビットマップのトレース（自動ベクター化）

Inkscapeには写真を自動で線画に変換する機能（「パス」→「ビットマップのトレース」）もあります。

### 手順
1. reference層の写真を選択（`reference`レイヤーのロックを一時解除してから選択する必要があります）
2. メニュー「パス」→「ビットマップのトレース」
3. プレビューを見ながら「しきい値」等を調整し、「適用」

### 注意点
- **自動トレースの結果はパスが汚くなりがち**です（ノードが異常に多い・ガタガタした輪郭・写真のノイズをそのまま拾う）
- 自動トレースしたパスをそのまま採用せず、**ノード編集(N)でパスを間引き・整形する「清書」作業が前提**になります。結局手作業に近い手間がかかることが多いです
- 写真は白背景のレストア済みエンジンなので、境界がはっきりしている部分（外形など）では有効な場合がありますが、**まずは手動トレース（3節の方法）を試すことを推奨**します。手が慣れてきてから、必要に応じて自動トレースを部分的に試すのがよいでしょう
- 自動トレースを使う場合も、結果は必ず`trace`レイヤーに置かれるようにしてください（レイヤーパネルで`trace`がアクティブになっているか確認）

---

## 7. 描き終わったらプレビューで確認する

`wiring/tools/trace/preview.html` は、トレース中のSVGを配線ビューア本番と同じ見た目（暗い背景＋淡い青の線）でプレビューできる確認ページです。

### 使い方
1. Inkscapeで`Ctrl+S`保存
2. `wiring/tools/trace/preview.html` をブラウザ（Chrome等）でダブルクリックして開く
   - ブラウザによっては `file://` で開くと正しく動かない場合があります。その場合は次のいずれかで代用してください:
     - VSCodeの「Live Server」拡張機能などで簡易サーバー経由で開く
     - Inkscape側で「ファイル」→「エクスポート」→PNG書き出しして目視確認する
3. ページ中央にファイルをドラッグ&ドロップする（またはボタンでファイル選択）
4. 読み込むと、reference/edge_hint層は自動的に隠れ、trace層の線だけが本番と同じ淡い青色(`#cfe6ff`)で表示されます
5. 気になる部分があればInkscapeに戻って修正し、保存 → もう一度プレビューにドラッグ&ドロップすれば差し替わります（同じファイルを再ドロップでOK）

これで「本番でどう見えるか」を確認しながら作業を進められます。

## 8. 著作権についてのメモ

テンプレートに埋め込んだ元写真は、FD Ricambi（イタリアのパーツショップ）の商品写真です。
できあがったトレース線画（SVG）を配線ビューアとして**公開する際の扱い（そのまま公開してよいか、加工の程度をどうするか等）は、ユーザー自身の判断事項**とします。
これは、既存の配線図PDF（大塚さん作成の原図）を公開リポジトリにpushしてよいかという課題と同種の論点です。判断が済むまでは、`wiring-viewer`ブランチ内で作業を進め、pushは控えてください。

## 困ったときは

- 間違えて`reference`や`edge_hint`のロックを外して動かしてしまった → `Ctrl+Z`で元に戻す、またはレイヤーパネルの鍵アイコンを再度クリックしてロックし直す
- 描いた線が消えた/見えない → レイヤーパネルで`trace`の目のアイコンがONになっているか確認
- 保存したのに反映されない → Inkscape側で本当に上書き保存（`Ctrl+S`）されているか確認（「名前を付けて保存」で別ファイルになっていないか）
